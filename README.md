# Example App

React Native mobile app.

## Requirements

- Node.js `>= 20`
- Xcode and CocoaPods for iOS
- Android Studio and Android SDK for Android

## Install

```bash
yarn
```

For iOS also install pods:

```bash
cd ios && pod install
```

## Run iOS

Start Metro:

```bash
yarn start
```

In another terminal run:

```bash
yarn ios
```

## Run Android

Start Metro:

```bash
yarn start
```

In another terminal run:

```bash
yarn android
```

## Useful Commands

```bash
yarn lint
yarn test
yarn format
```
